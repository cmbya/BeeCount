# 洞察统计改造（第2项）

- 周／月／年／全部切换，显示时间段，可选日期及前后周期。周从周一开始；月／年沿用账本自定义起始日，全部从本账本最早交易开始。
- 正在进行的周期只统计到今天结束；日均支出按已过去的自然日计算，包含零交易日。未来日期不计入本次统计。
- 收支卡片包含支出、收入、结余、日均支出、退款、退款收入。前四项按不计收支标记过滤；转账独立于收支。结余为普通收入减原支出，不暗自抵扣退款。
- 退款与退款收入同源于已关联的实际退款记录，两个指标不再产生写入。支出保留原金额，预算不改。
- 所有卡片可跳转当前账本和时间段对应明细；日均支出跳支出，结余跳收入＋支出，两项退款跳同一组退款。明细保留原币金额，汇总使用账本折算快照。
- 流转统计显示转账金额并可进入转账明细，不推断还款或借款语义。没有报销统计。
- 图表可切换支出／收入／结余，含零值时间桶与平均值；点柱后点金额标签进入对应时间桶明细。周月按日、年按账本月周期、全部按账本年周期聚合。
- 净资产趋势嵌入现有全局资产查询，切换净资产／总资产／总负债；时间段跟随统计周期，金额使用主币种。它不是当前账本专属资产。缺汇率币种不计入且提示；估值账户沿用当前估值，非历史估值账。
- 支出和收入各自显示一级分类饼图及明细，点开一级可展开二级，并可进入父级全部或单个二级的交易。兼容共享账本 synthetic 分类和旧直接记在一级下的交易。
- 现有月／年／账本海报入口保留；既有海报不支持周报，周视角分享禁用，不伪装为全账本分享。本轮不增加范围选择或报销模块。

新增的只读 service/model/provider 把卡片、序列、分类与明细收敛到一个交易快照，不修改数据库结构、账单金额、账户初始余额、预算或汇率。原统计页内部混合查询与渲染替换为分层组件，原账户趋势和分类图表复用。

补充周期、金额过滤、退款同源、分类汇总、共享分类、明细边界及页面跳转用例。仅静态复核，未运行 Flutter analyzer、测试、编译、Actions 或真机验收。后续需重点验证 iOS 小屏／大字体／暗色图表、跨期切换、实际账户多币种及长历史性能。
