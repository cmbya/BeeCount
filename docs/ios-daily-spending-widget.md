# 每日花销桌面小组件

新增独立的 iOS 中号 WidgetKit 小组件「每日花销」，保留旧组件；不包含「记一笔」按钮或新增账单深链。左侧显示今日已花、本月已花和还能花，右侧显示包含今天的近 7 个自然日支出柱状图。原生 SwiftUI 渲染文字和柱状图，无额外依赖，支持系统深浅色和添加页示例预览。

## 数据口径

- 使用 App 当前账本及其币种，不汇总其他账本。
- 今日：本地自然日半开区间；本月：包含今天的账本自定义月度周期，与首页相同。
- 已花金额使用统计仓库的支出合计，排除“不计入统计”，优先 nativeAmount。七日图表使用相同币种与支出筛选，无支出日补零。
- 还能花直接读取启用的总预算 usage.remaining，遵守独立的“不计入预算”标记，不以账户余额、日均可用或分类预算替代。未设置/禁用总预算显示「未设预算」；超支保留负数并标红。
- 收入、退款收入与转账不作为新增支出。预算沿用现有仓库口径，不另行改动退款计算规则。

## 刷新与有效期

根 ProviderContainer 注册独立观察器，合并统计、预算、同步、账本、语言和初始化状态的变化；App 恢复前台时也更新。仅在初始化就绪后取数，使用修订号及串行写入防止切账本时旧查询覆盖新结果。无需安装旧的图片型小组件，也不依赖图片渲染目录。

共享数据是一个版本化的 JSON 字符串，存储在已有 App Group 的 widget_daily_spending_v1 键中，仅含展示所需合计及日期，不含账单备注、附件或账户信息。随后请求刷新 BeeCountDailySpendingWidget。iOS 决定实际刷新时机，不能保证秒级更新。

组件预排次日零点的失效状态；跨日、跨周期或本地日边界因时区变化失效后，金额显示破折号并提示「打开 App 更新」，不会把历史数字标为今日。系统重新加载 timeline 只能重读快照，不能启动 Flutter 重新统计。打开 App 后重新取数。无有效快照时不会展示示例金额，示例数据仅用于添加页预览。

点击花销金额打开明细、剩余预算打开预算、七日图表打开统计；所有入口均不创建账单。

## 安装与验证边界

在新版本安装后长按桌面，添加 BeeCount 的「每日花销」中号组件。自行重签名时必须保留 Widget 扩展，并使主 App 与扩展的 App Groups 授权和配置一致。

本次用户要求仅改代码，不编译、不发布、不运行测试或 analyzer。新增了数据回归测试源码，尚未执行。后续获准构建后需检查 Swift 编译、不同屏幕宽度的金额布局、深浅色、添加页、记账/删改/同步/切账本刷新以及跨日失效状态。编译成功亦不能替代真机验收。
