# iOS 变量确认记账（个人 fork）

## 当前方案：同一条快捷指令里的两个动作

**准备账单 → 确认并记账**。第一个动作接收你准备的变量，只生成当前运行的待确认账单；第二个动作显示详情、逐项修改并在最终确认后保存一条账单。无需循环、字典、状态判断、第三个保存动作或 App 二次确认。

本次替代可添加的图片／文字记账入口；旧图文和原有自动截图入口仅保留隐藏兼容，不列为新建指令的动作。不恢复探针、测试、旧模板、自定义收支转账、单笔步骤或逐笔拆分动作。

## 参数顺序与变量

第一个动作按以下顺序展示参数：

| 顺序 | 字段 | 内容 |
|---|---|---|
| 1 | 金额 | 十进制金额文字，可接系统数字变量转换的文字；按账本精度校验，不静默舍入 |
| 2 | 类型 | 文字「支出／收入／转账」，也接受 expense／income／transfer；留空按支出 |
| 3 | 账本 | App 账本对象；留空使用当前账本，不随意挑第一个账本 |
| 4 | 分类 | 名称文字；可只传二级分类名，也可传完整路径 |
| 5 | 标签 | 单个标签名称文字；传入后预选，点击按 App 返回顺序轮换 |
| 6 | 账户 | 支出／收入使用的 App 账户对象 |
| 7 | 转出账户 | 转账使用的 App 账户对象 |
| 8 | 转入账户 | 转账使用的 App 账户对象，不能与转出账户相同 |
| 9 | 时间 | 使用传入的 Date 变量，不擅自换成当前时间；缺失时菜单待填写 |
| 10 | 备注 | 实际文本原样保留；不写变量名或 JSON 描述 |
| 11 | 不计预算（是／否） | 文字「是」表示排除预算，「否」表示计入；留空按否，仅支出有效 |
| 12 | 原始文本 | 本地规则匹配线索，不拼进备注，不调用 AI 或 OCR |
| 13 | 支付截屏 | 可选图片附件，不交给识别服务 |

「不计收入」已取消。类型与不计预算传入不认识的文字时明确显示待纠正，不能静默当成有效值保存。没有默认标签或账户回填，变量未提供就显示无／待选择。

### 二级分类匹配

App 中为「餐饮 → 食品」时，变量只写「食品」即可在唯一匹配时对应到子分类自己的 ID，菜单显示「餐饮/食品」，不会记到父分类。有多个「食品」或名称不存在时保留待选择状态，不能随便挑一个，也不能用规则覆盖明确提供但无效的名称。

分类留空才根据备注／原始文本执行个人规则、再执行内置关键词规则；不调用 AI。后续手动选择、清除分类或修改备注，不重新跑规则覆盖用户修改。切换类型后须重新确认分类。

## 快捷指令怎样连接

1. 添加 **准备账单**，展开并连接上述变量；标签例为「个人」，分类例为「食品」，不计预算例为「是」。
2. 添加 **确认并记账**，其「待确认账单」连接上一步的 **待确认账单整体输出**，不要切换为「账单内容」文字属性。
3. 运行。第二个动作显示确认菜单，修改完点 **确认提交**；不需要第三个保存动作。

支付截屏随待确认账单的文件属性自动传入第二步，无须重复连接。截图不塞进 JSON、剪贴板或全局草稿。最终确认后才编码保存附件，遵循 App 的保存原图设置；临时实体的文件属性能否完整经过目标系统和重签环境，仍须真机验证。

## 确认菜单与编辑

顺序为金额、类型、账本、分类、标签、账户（或转出账户／转入账户）、时间、备注、不计预算（仅支出）、确认提交、取消提交。

- 金额：菜单显示当前金额；编辑时直接请求系统数字输入，框内可以为空，不承诺动态预填。当前金额在提示中展示。正金额、范围和币种精度不合法时保留原值并返回菜单。
- 备注：使用本动作自己的系统文本输入；动态预填不作为强制条件。返回的实际文本覆盖备注，空文本表示清空；取消字段修改保留原值。目标系统是否允许空文本完成仍需实测。
- 标签：单标签点击轮换，例如个人 → 家庭 → 个人，不多选、不增加轮换中的「无」档。没有标签时显示无；无效／重名输入先明确选择。
- 分类：显示完整路径，按一级分组再选二级叶子；无子类的一级可直接选。有子类的父分类不作为保存目标。支持明确保留未分类。
- 类型、账本、账户：列表中选择；切换后不适用的引用需重新确认，备注等仍适用内容保留。跨币种／精度切换先确认并清空金额，不自动换算。
- 时间：展示并使用传入时间，可点击补齐／修改；不静默使用当前时间。
- 不计预算：文字行「是／否」，点击弹文字选项，不用开关。

每次修改返回同一菜单并展示最新值，不恢复初始变量覆盖后续编辑。金额、必需账户或时间缺失时先显示待补齐菜单，提交时明确提示，补齐前不能入账。转账必须选择两个不同的有效账户，不显示分类／预算。

## 保存和数据安全

一次只保存一条，不加入拆分；不增加不计收入、报销、还款、手续费或优惠券。最终提交前重新获取有效选项并校验引用，复用现有原子事务、附件、标签及请求凭证保存。原始文本只参与初始分类，不写入备注或额外元数据表。

最终值包括已修改金额、类型、账本、分类、标签、账户、时间、备注、预算标记；只有确认提交才落库。取消或提交前中断不写账单。字段取消在系统允许继续时保留原值；宿主直接终止不能承诺继续菜单，但不会因此触发保存。

提交结果不明时不允许回到编辑后更换内容重记：仅查询／重试同请求 ID 的同一最终 payload，或结束后在 App「最近提交凭证」和实际账单核对。重复运行准备账单会产生新请求，不能用它代替原请求重试。保存成功只代表本机，云端同步另看 App。

不改数据库版本，不删除历史交易、规则、预算、标签或已有拆分会话。授权范围仅本 fork 源码；用户手机自建快捷指令不自动删除。
