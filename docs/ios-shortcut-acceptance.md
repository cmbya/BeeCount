需求基线：用户提供的《需求文档 v1.0》《开发文档 v1.0》。后续用户已确认在 main 开发、App 内可视化规则管理，目标设备为 iPhone 17 / iOS 27.3 beta。以下区分代码与自动化证据、尚需目标真机验证的行为。

## 功能对照

| 需求 | 实现与验证证据 |
|---|---|
| FR-01 预算、FR-04 不计预算 | 复用现有预算；每笔保存 excludeFromBudget，与收支统计独立；300 元拆分测试验证预算仅增加 150 元 |
| FR-02 自建分类 | 每次读取有效收支分类，展示父级路径；提交在事务内重新验证，失效拒绝 |
| FR-03 分类规则 | 本次人工选择 > 个人规则 > 内置匹配 > AI；包含/完全匹配、账本范围、优先级；目标失效警告 |
| FR-05 标签 | 每笔多标签或空标签；拆分统计家庭 220 元、个人 80 元；回滚不留下关联 |
| FR-06 图片 AI | 原生压缩识别副本，复用现有视觉 AI 配置；识别只返回草稿；真实 HTTP 客户端连接本地兼容服务验证图片请求 |
| FR-07 OCR 文字 AI | Apple Vision 本机 OCR，或快捷指令系统取字；仅发文字；失败不自动上传原图；HTTP 请求验证不含图片 |
| FR-08 参数默认值 | 默认账本、账户、方式、标签、预算标记；显式空列表/false 优先，默认账户限定为同币种可交易账户 |
| FR-09 确认编辑 | 原生菜单修改金额、分类、账户、日期时间、备注、标签、预算；提交前验证，失败返回编辑 |
| FR-10 备注 | 点击直接请求输入，响应覆盖原备注、空响应清空、取消保留；不再有编辑/追加子菜单。系统输入静默结束和动态预填仍未解决，见下方记录 |
| FR-11 拆分 | 逐笔新增、编辑、删除、实时剩余；合计相等才提交；超额提示纠正；最多 100 笔 |
| FR-12 一次确认直接入账 | 编辑动作产生确认 JSON，组合动作直接提交；Flutter 路径无 App 二次确认 |
| QR-01 可靠性 | 整数最小单位计算；交易、标签、同步变更、分组、结果凭证同事务；同 ID 重放返回原结果，改内容冲突 |
| UX-01 可视化规则管理 | App 设置页新增/编辑/停用/删除、优先级、账本范围、收入/支出目标分类；Widget 测试验证操作 |
| 开发文档扩展 | 支出/收入/转账及账本切换；转账复用一条 transfer 记录和双边余额；收入/转账单笔且不显示预算 |

## 2026-11-06 Build 15 反馈修正（未编译、未运行测试）

- 账户：付款字段优先于模型线索；支持银行简称、信用/储蓄类型与尾号交叉校验。只在已有有效账户唯一兼容时预填，冲突/歧义仍需选择，不回退默认账户。
- 图片本地 OCR：用文字框的位置重建从上到下、从左到右的行，避免左侧标题列与右侧值列错配；文字输入缺少位置信息时仅接受明确行内/相邻单值，不猜测分列对应。
- 自动备注：字段标题与状态不再作为值，结构化账单按商户、商品、真实附言固定拼接，不用 AI 补写未标出的用途/附言。无明确字段的自由文字或 OCR 失败仍可能受模型输出影响，不能承诺所有内容逐字稳定。手动填写/编辑的备注不经过此清洗。
- 拆分：移除“开始拆分/返回”层，直接进入明细；第一笔确定完成前保留原账单，取消新明细不产生替代整笔。
- 五入口备注：移除“编辑/追加/清空重填”等操作菜单，点击直接请求输入，空响应清空、取消不覆盖。

**保留问题：**用户已选择继续留在快捷指令系统菜单，不跳 App。现有 requestValue 调用在目标系统上未弹输入框即静默结束的问题仍待运行诊断；该接口无动态初值参数，目前原备注只在提示中展示，不是输入框内预填。金额输入同样尚未解决，不能把菜单简化当作输入修复。新增/更新的 Dart 与 RunnerTests 仅补充逻辑回归覆盖，本次未执行；RunnerTests 的模拟输入无法覆盖系统弹窗。本次提交使用 `[skip ci]`，不触发编译、测试或发布。

## 系统询问输入改造（源码交付，未运行验证）

五入口新增兼容的模板模式及独立继续/最终保存动作。模板模式的金额（包含拆分）/备注/时间不调用旧 requestValue，而是返回输入类型、提示及当前值，由系统询问输入预填后返回。步骤变量保留本次草稿和菜单/输入记录，恢复原明细编辑位置；原子提交只在最终确认后进行，最终引用校验不复用缓存成功结果（历史失败校验只为精确恢复后续编辑而重放）。取消不入账，不新增磁盘草稿恢复。

RunnerTests 新增分步暂停/继续、原备注和金额初值、重复菜单不再弹、300 拆 80/150/70 与超额拒绝、空备注/取消等逻辑用例。本次没有执行这些测试或 iOS 编译。五份 unsigned.shortcut 仅在内存验证 XML/plist、动作/变量引用及生成一致性，未签名/导入/真机运行；详见 shortcuts/system-input/README.md。旧默认单动作路径仍保留旧输入限制，不能宣称所有已有快捷指令无需更新即可修复。
