# 已保存账单详情页改造

## 范围

已保存账单在首页公共列表、搜索、分类、标签、账户流水及日历中点击先打开详情页，不自动打开分类编辑与数字键盘。新建账单和长按复制入口不改。

布局参照用户提供的分组卡片：顶部编辑/删除操作；分类与账本；时间、金额、币种、账户（转账含转入账户）；备注、标签与图片；不计收支与不计预算。备注长内容换行，浅/深色沿用 BeeTokens。只使用现有功能，不新增优惠、报销、退款或存模板操作。

各行直接打开对应字段输入/选择，确认后保存该字段，取消不写入。备注直接预填全文，空字符串确认清空。图片进入已有预览或相机/图库选择，沿用已有附件服务。预算仅支出显示，收支标记对收入/支出显示，转账隐藏两者。顶部编辑仍进入原完整编辑器；类型行对收入/支出直接改分类，转账类型行与转账币种行进入完整编辑器，沿用原有双账户约束。

## 数据安全

单字段服务在事务中读最新账单并合并字段，保留分类、账户的共享引用 override、转账另一端、标签和币种折算快照；修改金额按原隐含汇率缩放。按交易所属账本加载可用资源，检查编辑权限和引用存在性，不改首页当前账本。只读共享账本禁用写操作。

个人账本间移动沿用原 Repository，并提前验证折算汇率。共享账本间搬移需要资源重映射，此页不开放，避免将其他账本引用静默带入。更改币种提示清空已选账户，并要求有效汇率；转账币种行进入原完整编辑器处理双账户约束。
